# Góc nhỏ của Thành

Blog cá nhân chạy bằng GitHub Pages và quản lý nội dung qua Pages CMS.

## Đăng bài

1. Mở https://app.pagescms.org và đăng nhập bằng GitHub.
2. Chọn repository `thanhqn9895/mybio`, nhánh `main`.
3. Chọn **Bài viết** → **New Bài viết**.
4. Điền nội dung, tải ảnh, bật **Đăng công khai**, rồi lưu.

GitHub Pages sẽ tự dựng lại trang sau mỗi lần lưu.
